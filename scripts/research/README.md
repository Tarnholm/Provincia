# Research scripts

One-off probes from the income / trade / trait calibration work, moved out of
the repo root on 2026-09-21. They are not part of the app, the tests or the
build. Each reads the RIS mod at `C:/RIS/RIS/data` and a calibration save from
the game's save folder, so they only run on a machine that has both.

Run from anywhere: `node scripts/research/<name>`.
