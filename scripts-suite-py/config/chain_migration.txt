; ============================================================================
; Building-chain migration config  (used by the "Migrate Building Chain" step)
; ----------------------------------------------------------------------------
; One [migration] block per OLD chain you are retiring. All blocks are applied
; in a single run. Lines starting with ; are comments.
;
;   old_chain    name of the chain being retired (as it appears: `building <x>`)
;   old_levels   its level names in tier order (space separated)
;   new_chains   the chain(s) that replace it (space separated)
;   remap        old_level->token pairs. The token replaces every
;                `building_present[_min_level] <old> <level>` reference in the
;                EDB. Point it at an alias that ORs all the new chains at that
;                tier (the modder's cropfarming_level_N aliases already do this)
;                so the reference is "tied to all" the new chains at once.
;                Any old level with no remap entry is left untouched and listed
;                in the report.
;   descr_strat  remove (default) = delete the old prebuilts from settlements;
;                keep = leave them (only useful before the EDB block is gone).
;
; The tool also SCANS traits, ancillaries and localization and REPORTS what
; needs hand-finishing (missing new-chain text keys, per-culture .tga, trigger
; rewrites). It never fabricates localization or art.
; ============================================================================
